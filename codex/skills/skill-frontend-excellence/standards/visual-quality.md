# Visual quality

Verifiable, not taste-as-authority.

| Check | Fail when |
|---|---|
| Hierarchy | Primary action is not findable in 5 seconds on the first viewport |
| Contrast | Body text vs surface below 4.5:1 (except a documented active design-system exception on non-body brand fills) |
| Typography | More than three ad-hoc font sizes on one screen; line length > 80ch for reading text |
| Spacing | Mixed spacing units that ignore the active design-system spacing scale |
| Alignment | Controls in a form row have different heights/baselines without a reason |
| Density | Matches Design Profile (`compact` / `medium` / `comfortable`) |
| Clutter | Decorative elements that do not carry status or action |
| Generic AI look | Purple/cyan gradient, glass cards, four metric tiles, leftover "dashboard" chrome |

Creativity HIGH still uses the active design system's components and tokens. Personality comes from composition, imagery, density, and motion — not from forking the system.
