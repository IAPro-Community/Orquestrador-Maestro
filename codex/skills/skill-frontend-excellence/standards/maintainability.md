# Maintainability

- If a rule must be copied into many apps, it belongs in the active design system or in this skill — not in each repository.
- Product-specific personality belongs in the project's configured Design Profile.
- New shared components require evidence of transversal use and a written proposal. Do not promote product widgets into the design system automatically.
- Keep adapters ignorant of design-system internals: read public metadata exports or generated files named by the project.
- Prefer generated metadata over handwritten catalogs.
