# Documentation request examples

## Complete product documentation

> Documente completamente este projeto. Descubra as capacidades reais, verifique-as e atualize README, Quick Start, guias e referências aplicáveis. Não documente como fato nada que não tenha evidência suficiente.

## README and Quick Start

> Crie ou melhore README e Quick Start. O Quick Start deve chegar da instalação/configuração até a primeira ação útil e os comandos devem ser verificados quando possível.

## Coverage audit

> Audite a documentação e identifique funcionalidades relevantes que não estão documentadas, páginas obsoletas e áreas que não puderam ser verificadas.

## Documentation drift

> Compare o produto atual com a documentação e reporte documentation drift, especialmente README, CLI, API/OpenAPI, variáveis de ambiente e guias de features.

## Visual documentation

> Identifique quais fluxos realmente precisam de screenshots, GIFs, vídeos ou Mermaid. Descreva exatamente o que deve ser capturado e delegue a captura ao mecanismo existente.
