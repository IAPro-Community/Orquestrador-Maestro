# Product Documentation / Deep Wiki

Canonical skill: `SKILL.md`.

Use this skill for evidence-backed product/repository documentation: README, TL;DR, Quick Start, feature guides, API/CLI/configuration references, troubleshooting, visual documentation requirements, documentation coverage and drift detection.

It does not implement product features, replace QA/release gates, own Git workflow, automate browsers itself, or create a parallel evidence store.

The canonical ID remains `skill-deep-wiki` for compatibility; Product Documentation is the expanded scope and preferred user-facing concept.
