# Workflow: IMPROVE

Default posture: `EVOLVE`. Default creativity: `LOW`. Raise to `MEDIUM` only when the user asks to restructure UX, not just polish.

## Sequence

1. Name the user task of the screen (one sentence).
2. Capture current screenshots.
3. Fix comprehension and layout stability before aesthetics.
4. Prefer token/spacing/type/contrast changes over new components.
5. Keep active design-system components; restyle via tokens and local styles, not wrappers that fork behavior.
6. Validate responsive and accessibility (`standards/responsive.md`, `standards/accessibility.md`).
7. Compare before/after. Unrelated visual drift is a bug.

## Typical IMPROVE work

- contrast and focus
- spacing rhythm
- form grouping and labels
- mobile wrapping
- empty/error states
- reducing clutter
