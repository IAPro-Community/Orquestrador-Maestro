# Freebuff

O Freebuff usa o contrato compartilhado do Maestro por meio de `AGENTS.md`, `knowledge.md` e `.agents/skills`.

Não existe um perfil proprietário para copiar neste diretório. O instalador registra o componente `freebuff` e sincroniza as skills para `.agents/skills`, preservando a configuração, autenticação, sessões, cache, logs e histórico do Freebuff.

Consulte [a documentação de integração](../../docs/freebuff-integration.md) para instalação, reinício, MCP, agentes locais e publicação para outras pessoas.
